# kabirbaigsai - AI Multimodal Generator Studio

A complete, self-contained single-page web app for **kabirbaigsai** supporting both text and image generation using Google's Gemini and Imagen APIs.

## Features
- **Text Generation Studio**: Generate answers, creative stories, code, and explanations using Gemini 2.5 models.
- **Image Generation Studio**: Generate artwork, concept designs, and photography using Imagen 3 with aspect ratio adjustments and preset art styles.
- **Local Key Storage**: Secure client-side API key configuration saved in browser local storage.
- **Markdown & Code Highlighting**: Formatted markdown rendering for responses.

## Setup & Running
1. Unzip the archive.
2. Open `index.html` in any modern web browser.
3. Click **Set API Key** in the top navigation bar and enter your Google Gemini API key.
4. Switch between Text Studio and Image Studio to start creating!
